# VOT: фиксированная надбавка громкости перевода

Форк [ilyhalight/voice-over-translation](https://github.com/ilyhalight/voice-over-translation), версия userscript **1.11.17.1**.

## Contributors и AI-участие

**xtalia** — инициатор, требования и владелец форка. Реализация функции, тесты и проверки выполнены с помощью **Hermes Agent (Nous Research), использующего модели OpenAI**. Владелец форка не заявляет, что написал эти изменения вручную. Авторство исходного VOT остаётся за его авторами.

## Установка

Откройте [vot.user.js](https://raw.githubusercontent.com/xtalia/voice-over-translation/master/dist/vot.user.js) в браузере с Tampermonkey или Violentmonkey. Замените исходный VOT этим скриптом; не запускайте обе версии одновременно. Адреса автоматических обновлений указывают на этот форк.

## Настройка

В настройках VOT, в разделе настроек перевода:

1. Включите **«Связать громкость перевода и видео»**.
2. В **«Режим связи громкости»** выберите **«Оригинал + фиксированная надбавка»**.
3. Выберите пресет **0, 5, 10, 15, 20, 30, 50, 75 или 100 п.п.**, либо введите собственное целое значение **0–100**.

Это процентные пункты, а не множитель: оригинал **10%** с надбавкой **10 п.п.** даёт перевод **20%**. Перевод ограничен **100%**. При громкости оригинала **0** или выключении звука перевод тоже замолкает. После снятия mute уровень восстанавливается. В этом режиме громкость задаёт оригинальный плеер, поэтому отдельный ползунок перевода заблокирован.

Прежний режим **«Как раньше: одинаковое изменение»** сохранён и используется по умолчанию. Надбавка и режим сохраняются между перезагрузками страницы.

## Обновления от оригинала

Наши hooks помечены в исходниках `[VOT-FORK:...]`. Карта всех изменений, исходная база, резервный патч и порядок объединения обновлений — в [FORK-MAINTENANCE.md](FORK-MAINTENANCE.md). Сначала объединяйте исходники, затем пересобирайте userscript: замена bundle на оригинальный файл удалит функцию.

## Проверки и сборка

```sh
bun install --frozen-lockfile
bun test tests/volume-link-offset.test.ts tests/fork-metadata.test.ts
bunx tsc -p src/tsconfig.json --noEmit
bun run lint
bun run build:gm
```

`tests/browser-volume-offset.html` — локальная браузерная фикстура с настоящими компонентами настроек и HTML video/audio, без обращения к API перевода. Для запуска через Vite нужны глобальные константы сборки (`DEBUG_MODE`, `IS_EXTENSION`, `REPO_BRANCH`, `VOT_VERSION`, `VOT_AUTHORS`, `AVAILABLE_LOCALES`).

На исходном коммите `af99cad` подтверждены две существующие ошибки полного набора тестов (`smart-ducking`, `translationCommands`) и ошибки типов в двух Vite-конфигурациях. Эти же ошибки воспроизводятся на неизменённом upstream; изменения надбавки не добавляют новых сбоев. Типизация `src` и сборка userscript проверяются отдельно.
